# צ׳ק ליסט הריון לפי שבועות

אתר סטטי (קובץ `index.html` אחד) עם משימות, בדיקות, תורים וזכויות לפי שבועות ההריון, לפי מסלול המעקב בישראל.

- הזנת תאריך וסת אחרונה או תאריך לידה משוער
- בחירת קופה להצגת החזרי סל ההריון בשב״ן
- הוספת משימות אישיות לכל שבוע
- הסימונים נשמרים ב-localStorage של הדפדפן

פריסה: Vercel (סטטי, בלי build).
